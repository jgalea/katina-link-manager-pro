**Auto-linking, link opportunities, AI link suggestions and coupons for Katina Link Manager.**

## What it adds

- Auto-linking: links your Katina links into post content automatically, with a background refresh when a post changes.
- Link Opportunities: lists posts that mention a link's keyword but don't link to it yet, with one-click insertion.
- AI link suggestions: a block editor sidebar that suggests links while you write, using the AI provider and API key you set on the Pro settings page.
- Coupons and deals: a coupon post type with categories and tags, a `[katina_coupons]` shortcode, a Katina Coupons block, an importer, a WP-CLI import command, and Affcoups compatibility.
- Revenue tracking: a revenue table and report for your affiliate links.
- REST API under `katina-link-manager-pro/v1` for suggestions and coupon events.

## Requirements

- Katina Link Manager (free), installed and active
- WordPress 6.2 or later
- PHP 8.0 or later

## Install

1. Download `katina-link-manager-pro.zip` from the latest release on the Releases page.
2. In WordPress, go to Plugins > Add New > Upload Plugin and upload the zip.
3. Activate it. There is no license key.

Updates arrive through the WordPress updates screen.

Katina Pro is free during early access.
